### 4.1 基础变换与 4.1.1 平移

- 线性变换保持向量加法与标量乘法；旋转和缩放属于线性变换。
- 平移不是线性变换。齐次坐标将线性变换和平移统一为 `4×4` 仿射矩阵运算。
- 点写作 `(x, y, z, 1)`，方向向量写作 `(x, y, z, 0)`；平移会影响点而不影响方向向量。
- 平移的逆为反向平移：`T(t)^-1 = T(-t)`。

### 4.1.7 法线变换

设原切向量为 `t`，原法线为 `n`，二者垂直，因此：

```text
n^T t = 0
```

几何体经过线性变换 `A` 后，切向量直接变为 `t' = At`。设法线使用待求矩阵 `B` 变换，即 `n' = Bn`。为了让变换后的法线仍垂直于表面，需要：

```text
(n')^T t' = 0
(Bn)^T(At) = 0
n^T B^T A t = 0
```

要让这个关系对所有原本垂直的 `n` 和 `t` 都成立，应使：

```text
B^T A = I
B^T = A^-1
B = (A^-1)^T
```

因此法线变换公式为：

```text
n' = normalize((A^-1)^T n)
```

其中 `A` 通常取模型矩阵或模型观察矩阵左上角的 `3×3` 线性部分，不包含平移和透视投影。纯旋转时 `(A^-1)^T=A`，可以直接使用旋转矩阵；存在非均匀缩放或错切时必须使用逆转置。变换后通常还要归一化，因为矩阵变换和后续光栅化插值都可能改变法线长度。

### 4.1.8 逆矩阵的计算

逆矩阵用于撤销原变换。若 `p'=Mp`，且 `M` 可逆，则 `p=M^-1p'`。

如果已知矩阵由哪些基础变换组成，优先分别对各变换求逆，并把组合顺序反过来。如果矩阵是正交矩阵，其逆矩阵就是转置。如果不知道矩阵由什么变换组成，则需要使用通用求逆算法，例如：

- 伴随矩阵法；
- 克拉默法则；
- 高斯消元；
- LU 分解。

矩阵存在逆的条件是 `det(M)≠0`。若 `det(M)=0`，矩阵是奇异矩阵，变换丢失了信息，无法完整恢复原输入。

本节最重要的两个公式：

```text
(AB)^-1 = B^-1 A^-1
```

组合变换求逆时，不仅要对每个矩阵求逆，还必须颠倒矩阵顺序。

```text
R^-1 = R^T
```

旋转矩阵 `R` 是正交矩阵，满足 `R^TR=I`，所以它的逆矩阵等于转置矩阵。

#### 2×2 与 3×3 行列式的计算

对于 `2×2` 矩阵：

```text
    [ a  b ]
A = [ c  d ]
```

行列式为主对角线乘积减去副对角线乘积：

```text
det(A) = |A| = ad - bc
```

对于 `3×3` 矩阵：

```text
    [ a  b  c ]
A = [ d  e  f ]
    [ g  h  i ]
```

沿第一行进行代数余子式展开：

```text
det(A) = a(ei - fh) - b(di - fg) + c(dh - eg)
```

也可以写成六项形式：

```text
det(A) = aei + bfg + cdh - ceg - bdi - afh
```

第一行展开时的符号依次为 `+、-、+`。更一般的代数余子式符号呈棋盘状：

```text
[ +  -  + ]
[ -  +  - ]
[ +  -  + ]
```

例如：

```text
    [ 1  2  3 ]
A = [ 0  4  5 ]
    [ 1  0  6 ]

det(A)
= 1(4×6 - 5×0) - 2(0×6 - 5×1) + 3(0×0 - 4×1)
= 24 + 10 - 12
= 22
```

若 `det(A)=0`，矩阵不可逆；若 `det(A)≠0`，方阵可逆。

## 4.2 特殊矩阵变换与运算

### 4.2.1 欧拉变换

欧拉变换用三个角度描述物体或相机的朝向。书中约定默认向前方向为 `-z`、向上方向为 `+y`，并使用：

- `h`：Head/Yaw，绕 `y` 轴左右转；
- `p`：Pitch，绕 `x` 轴抬头或低头；
- `r`：Roll，绕 `z` 轴侧倾。

书中采用的欧拉变换为：

```text
E(h,p,r) = Rz(r) Rx(p) Ry(h)
```

在列向量约定下，矩阵从右向左作用，因此实际执行顺序为 Head/Yaw、Pitch、Roll。三维旋转通常不可交换，即 `RxRy ≠ RyRx`，所以欧拉角必须连同旋转轴和旋转顺序一起解释。

欧拉变换是多个旋转的组合，因此仍然是正交矩阵：

```text
E^-1 = E^T
     = Ry^T Rx^T Rz^T
     = Ry(-h) Rx(-p) Rz(-r)
```

撤销组合旋转时，需要令每个角度取反，并颠倒变换顺序。

### 4.2.2 从欧拉变换中提取参数

这一节执行 4.2.1 的反向过程：已知旋转矩阵 `E`，提取其中的 Head/Yaw `h`、Pitch `p` 和 Roll `r`。

平移与欧拉角无关，因此只需观察完整变换矩阵左上角的 `3×3` 旋转部分：

```text
    [ e00  e01  e02 ]
E = [ e10  e11  e12 ]
    [ e20  e21  e22 ]
```

书中采用的旋转顺序为：

```text
E = Rz(r) Rx(p) Ry(h)
```

把三个旋转矩阵相乘，得到：

```text
    [ cos(r)cos(h) - sin(r)sin(p)sin(h)   -sin(r)cos(p)   cos(r)sin(h) + sin(r)sin(p)cos(h) ]
E = [ sin(r)cos(h) + cos(r)sin(p)sin(h)    cos(r)cos(p)   sin(r)sin(h) - cos(r)sin(p)cos(h) ]
    [              -cos(p)sin(h)                sin(p)                 cos(p)cos(h)             ]
```

从矩阵元素 `e21` 可以直接读出：

```text
e21 = sin(p)
p = arcsin(e21)
```

对于 Head/Yaw，观察：

```text
e20 = -cos(p)sin(h)
e22 =  cos(p)cos(h)
```

当 `cos(p)≠0` 时，两者具有共同因子 `cos(p)`，可得到：

```text
h = atan2(-e20, e22)
```

对于 Roll，观察：

```text
e01 = -sin(r)cos(p)
e11 =  cos(r)cos(p)
```

同样可得到：

```text
r = atan2(-e01, e11)
```

因此，在非万向节锁情况下，书中的欧拉角提取公式为：

```text
h = atan2(-e20, e22)
p = arcsin(e21)
r = atan2(-e01, e11)
```

使用 `atan2(y,x)` 而不是 `arctan(y/x)`，是因为 `atan2` 同时保留 `x`、`y` 的符号信息，可以判断角度所在象限，并避免直接除以零。

上述公式与旋转顺序绑定，只适用于 `E=Rz(r)Rx(p)Ry(h)` 这一约定。换用其他欧拉角顺序时，矩阵展开和角度提取公式也会改变。当 `cos(p)=0`，即 `p=±π/2` 时，用于分别提取 `h` 和 `r` 的元素退化为零，进入万向节锁情况，详见问答记录 Q10。

## 基础公式速查：矩阵加法与矩阵乘法

### 矩阵加法：相同位置的元素相加

只有行数、列数都相同的两个矩阵才能相加。若 `A`、`B` 都是 `m×n` 矩阵，则结果 `C=A+B` 也是 `m×n` 矩阵：

$$
c_{ij}=a_{ij}+b_{ij}
$$

`i` 表示行，`j` 表示列。例如：

```text
[ a  b ]   [ e  f ]   [ a+e  b+f ]
[ c  d ] + [ g  h ] = [ c+g  d+h ]

[ 1  2 ]   [ 5  6 ]   [  6   8 ]
[ 3  4 ] + [ 7  8 ] = [ 10  12 ]
```

矩阵加法满足交换律与结合律：`A+B=B+A`，`(A+B)+C=A+(B+C)`。

### 矩阵乘法：左矩阵的行与右矩阵的列做点积

若 `A` 是 `m×n` 矩阵，`B` 是 `n×p` 矩阵，则乘积 `C=AB` 是 `m×p` 矩阵。乘法要求左矩阵的列数等于右矩阵的行数：

$$
c_{ij}=\sum_{k=1}^{n}a_{ik}b_{kj}
$$

也就是：取 `A` 的第 `i` 行与 `B` 的第 `j` 列，对应元素相乘后求和，得到结果的第 `i` 行、第 `j` 列元素。这里下标从 1 开始。

```text
[ a  b ] [ e  f ]   [ ae+bg  af+bh ]
[ c  d ] [ g  h ] = [ ce+dg  cf+dh ]

[ 1  2 ] [ 5  6 ]   [ 1×5+2×7  1×6+2×8 ]   [ 19  22 ]
[ 3  4 ] [ 7  8 ] = [ 3×5+4×7  3×6+4×8 ] = [ 43  50 ]
```

矩阵乘列向量是同一个规则的特例：

```text
[ a  b ] [ x ]   [ ax+by ]
[ c  d ] [ y ] = [ cx+dy ]
```

重要性质（假设各运算的维度匹配）：

- 通常不满足交换律：`AB≠BA`；有时 `AB` 可以计算，`BA` 却因维度不匹配而无法计算。
- 满足结合律：`(AB)C=A(BC)`；可以改变括号，但不能任意改变矩阵顺序。
- 满足分配律：`A(B+C)=AB+AC`，`(A+B)C=AC+BC`。
- 单位矩阵不改变结果：`I_m A=A I_n=A`，其中 `A` 为 `m×n` 矩阵。
- 普通矩阵乘法不是对应位置的元素相乘；逐元素相乘是另一种运算，称为 Hadamard 积。

在本章的列向量约定下，组合变换用乘法表达：`p'=TRSp` 表示先缩放，再旋转，最后平移。`T+R+S` 不能表示依次执行这三个变换。

## 基础公式速查：点积与叉积

设三维向量 `a=(a_x,a_y,a_z)`、`b=(b_x,b_y,b_z)`；非零向量的夹角为 `θ∈[0,π]`。

| 运算 | 结果与几何意义 | 典型应用 |
| --- | --- | --- |
| 点积 `a·b` | 一个数：提取沿指定方向的分量；单位化后表示夹角余弦 | 投影、求坐标分量、判断垂直、方向接近程度、平面两侧判断 |
| 叉积 `a×b` | 一个向量：垂直于两向量；长度等于它们张成的平行四边形面积 | 求法线、构造正交基、求面积、判断平行、二维左右侧判断 |

### 点积：同位乘，再求和

$$
a\cdot b=a^Tb=a_xb_x+a_yb_y+a_zb_z
=\|a\|\|b\|\cos\theta
$$

- 对两个非零向量：点积为正表示夹角小于 90°，为零表示垂直，为负表示夹角大于 90°。
- 若 `u` 是单位向量，`a·u` 是沿 `u` 的有符号投影长度，投影向量为 `(a·u)u`。
- 满足交换律：`a·b=b·a`。比较方向接近程度时先单位化，避免长度影响。

### 叉积：循环取另外两轴，正乘减反乘

$$
a\times b=
\begin{bmatrix}
a_yb_z-a_zb_y\\
a_zb_x-a_xb_z\\
a_xb_y-a_yb_x
\end{bmatrix}
$$

按 `x→y→z→x` 循环记忆：结果的 `x、y、z` 分量分别使用 `yz、zx、xy`；中间项是 `zx`，不要写反。

$$
\|a\times b\|=\|a\|\|b\|\sin\theta
$$

- 非平行时，方向由从 `a` 转向 `b` 的右手定则确定；平行或含零向量时，叉积为零。
- 交换顺序会反向：`a×b=−(b×a)`。三角形面积为 `½‖a×b‖`，其中 `a、b` 是从同一顶点出发的两条边。
- 对互相垂直的单位向量 `r、s`，`t=r×s` 自动成为同时垂直于二者的单位向量。

### 如何选择：边的同侧判断

二维中，令有向边 `e=B−A`，待测点位移 `v=P−A`。在 `x` 向右、`y` 向上的约定下：

$$
\operatorname{cross2D}(e,v)=e_xv_y-e_yv_x
=\|e\|\|v\|\sin\varphi
$$

这里 `φ` 是从 `e` 转向 `v` 的有向角。结果为正表示点在边的左侧，为负在右侧，为零在边所在直线上。它是三维叉积的 **z 分量**，有正负；叉积的长度始终非负。

点积也能判断同侧，但需使用边的左法线 `n=(−e_y,e_x)`：

$$
n\cdot v=(-e_y)v_x+e_xv_y=\operatorname{cross2D}(e,v)
$$

直接算 `e·v` 测量的是沿边的分量，无法区分边两侧的镜像点：`cos(−φ)=cosφ`；而二维叉积的符号会翻转：`sin(−φ)=−sinφ`。

对于逆时针排列的非退化二维三角形，对三条有向边分别计算上述结果：全部非负表示点在内部或边界上，全部严格为正表示严格在内部；顺时针排列则反转符号判断。

**选择原则：需要“沿某方向有多少”用点积；需要“两方向张成的面积、法线或转向”用叉积。同一个问题可以通过改变几何表达，使用不同运算。**

## 问答记录

### Q11：矩阵乘法、矩阵加法是否已经记录公式？

**答：** 本次检查发现，已有笔记记录了组合变换、矩阵求逆以及乘法通常不满足交换律等内容，但尚未单独记录矩阵加法和乘法的通用元素公式。现已补充到本章“基础公式速查：矩阵加法与矩阵乘法”，包含维度要求、计算公式、数值例子和常用性质。加法是同型矩阵对应元素相加；乘法是左矩阵的行与右矩阵的列做点积。

### Q1：点 `(x, y, z, 1)`、方向向量 `(x, y, z, 0)` 是人为规定的吗？为什么？

**答：** 这是齐次坐标的数学约定，但其取值有明确目的：让平移也能写进一次 `4×4` 矩阵乘法中。三维线性变换只需 `3×3` 矩阵；平移是「加上常量」，不能由普通 `3×3` 矩阵表达。引入第四分量 `w` 后，平移项乘以 `w`：点的 `w=1`，所以会得到平移；方向向量的 `w=0`，所以平移项自动消失。

点代表空间中的位置，移动它是有意义的；方向向量代表朝向、速度、边或法线的方向，没有独立位置，因此整体平移场景时它不应改变。这里的 `0` 和 `1` 不是唯一可用的齐次表示：任意 `w≠0` 的 `(xw, yw, zw, w)` 都表示同一点，除以 `w` 后恢复为 `(x, y, z)`；图形 API 通常选 `w=1` 作为标准点表示，方便计算。方向对应 `w=0`，不能做透视除法，也可理解为「无穷远处的点」所表示的方向。

### Q2：为什么 `w=0` 就不受平移影响？用数学计算证明。

**答：** 对列向量约定，任意仿射变换都可写为块矩阵：

```text
M = [ A  t ]
    [ 0  1 ]
```

其中 `A` 是 `3×3` 的线性部分（旋转、缩放等），`t` 是三维平移向量。对齐次向量 `(q, w)`，结果为：

```text
M × (q, w) = (Aq + tw, w)
```

平移总是以 `tw` 的形式出现。因此点取 `w=1` 时结果为 `Aq+t`，会得到平移；方向取 `w=0` 时结果为 `Aq`，平移项严格变为零。纯平移时 `A=I`，所以方向向量原样不变。例如 `T(10,0,0) × (3,0,0,0)^T = (3,0,0,0)^T`。这也对应方向是两点之差：`(B,1)-(A,1)=(B-A,0)`；将两点共同平移后，位移在相减时抵消。

### Q3：点积的公式是什么？`n^T t` 是什么含义？

**答：** 对三维向量 `a=(a_x,a_y,a_z)` 和 `b=(b_x,b_y,b_z)`，点积的分量公式为 `a·b=a_xb_x+a_yb_y+a_zb_z`。若二者写成列向量，同一个运算可写成矩阵形式 `a^T b`。点积也可写为 `a·b=|a||b|cosθ`，其中 `θ` 是两向量夹角。因此单位向量的点积就是夹角的余弦；点积为零表示两个非零向量垂直。

### Q4：从 `B^T=A^{-1}` 得到 `B=(A^{-1})^T` 使用了什么公式？

**答：** 对等式两边同时转置，得到 `(B^T)^T=(A^{-1})^T`；再使用转置的对合性质 `(M^T)^T=M`，左边化为 `B`，所以 `B=(A^{-1})^T`。这里右边暂时不需要继续化简；若 `A` 可逆，还可用 `(A^{-1})^T=(A^T)^{-1}`。在法线变换中，若切向量使用 `A` 变换、法线使用待求矩阵 `B` 变换，保持垂直要求 `B^T A=I`，由此得到 `B^T=A^{-1}`，最终得到法线矩阵 `B=(A^{-1})^T`。

### Q5：法线变换公式既然固定，为什么纯旋转时又能直接使用旋转矩阵？

**答：** 通用公式始终是 `n' = normalize((A^-1)^T n)`。纯旋转矩阵 `R` 是正交矩阵，满足 `R^-1=R^T`，所以 `(R^-1)^T=(R^T)^T=R`；直接乘 `R` 只是通用公式在纯旋转情况下的化简。若 `A=sR` 是旋转加正的均匀缩放，则逆转置为 `(1/s)R`，与直接乘 `sR` 得到的方向相同，归一化后结果一致。非均匀缩放或错切会改变法线方向，无法通过一次归一化消除差异，因此必须使用通用的逆转置矩阵。

### Q6：纯旋转变换 `A` 能否直接同时用于切向量和法线，并保持二者垂直？

**答：** 可以。设 `t'=At`、`n'=An`，则变换后的点积为 `(n')^Tt'=(An)^T(At)=n^TA^TAt`。纯旋转矩阵是正交矩阵，满足 `A^TA=I`，所以结果为 `n^Tt=0`。因此旋转会让切向量和法线一起旋转相同角度，并保持长度、夹角和垂直关系。这个结论依赖 `A` 是纯旋转（更一般地说是正交变换）；普通非均匀缩放或错切不满足 `A^TA=I`。

### Q7：什么是正向变换？

**答：** “正向变换”不是固定的变换类型，而是相对于当前讨论人为选定的原方向。若定义矩阵 `M` 把原坐标 `p` 变为目标坐标 `p'=Mp`，那么 `M` 就称为这次讨论中的正向变换；把 `p'` 恢复为 `p` 的 `p=M^-1p'` 则是逆向变换。例如将模型空间位置变到世界空间时，模型矩阵是正向变换，其逆矩阵负责从世界空间变回模型空间。改变讨论目标后，“正向”的含义也会随之改变。

### Q8：如何从 `p'=Mp` 推导出 `p=M^-1p'`？

**答：** 已知正向变换 `p'=Mp`，并假设 `M` 可逆。为了消去 `p` 左边的 `M`，在等式两边同时左乘 `M^-1`：

```text
M^-1 p' = M^-1(Mp)
          = (M^-1M)p
          = Ip
          = p
```

所以 `M^-1p'=p`，交换等式左右可写为 `p=M^-1p'`。这里使用了逆矩阵定义 `M^-1M=I` 和单位矩阵性质 `Ip=p`。由于矩阵乘法通常不满足交换律，必须左乘逆矩阵，不能随意写成 `p'M^-1`。

### Q9：为什么正交矩阵的逆矩阵等于它的转置？

**答：** 正交矩阵按定义满足：

```text
M^T M = I
```

而逆矩阵 `M^-1` 的定义之一是：

```text
M^-1 M = I
```

比较两个等式可见，`M^T` 和 `M^-1` 左乘同一个 `M` 后都得到单位矩阵，因此：

```text
M^-1 = M^T
```

旋转矩阵 `R` 的列向量是两两垂直的单位向量，因此 `R^TR=I`，它属于正交矩阵。于是旋转矩阵求逆只需转置：

```text
R^-1 = R^T
```

几何上，`R^-1` 表示撤销旋转，即绕同一旋转轴转过相反角度。

### Q10：为什么 `p=±π/2` 时无法分别提取 Head 和 Roll？什么是万向节锁？

**答：** 书中的欧拉变换为 `E=Rz(r)Rx(p)Ry(h)`。正常情况下可用 `h=atan2(-e20,e22)` 和 `r=atan2(-e01,e11)` 分别提取两个角度；但这四个矩阵元素都含有因子 `cos p`。当 `p=±π/2` 时，`cos p=0`，它们全部变成零，两个公式都退化为无定义的 `atan2(0,0)`。

以 `p=π/2` 为例，把 `sin p=1`、`cos p=0` 代入完整矩阵后得到：

```text
    [ cos(r+h)   0   sin(r+h)  ]
E = [ sin(r+h)   0  -cos(r+h)  ]
    [    0       1      0      ]
```

矩阵中只剩下 `r+h`，不再分别包含 `r` 和 `h`。例如 `(h=20°, r=30°)` 与 `(h=10°, r=40°)` 的和都为 `50°`，在 `p=90°` 时会产生同一个最终旋转矩阵，因此无法从矩阵判断原来使用了哪一组角度。几何上，这是 Pitch 转到 `±90°` 后 Head 与 Roll 的旋转轴重合，两个参数控制同一个旋转方向，三个独立旋转自由度暂时只剩两个。物体仍能处于该朝向，旋转矩阵也仍然有效；失效的是这套欧拉角参数对朝向的一一表达和稳定提取能力。

### Q12：怎么看出 R 是右手坐标系下绕 z 轴旋转 90° 的矩阵？

**答：** 必须先明确约定：使用右手坐标系、列向量，且 `v'=Rv` 表示主动旋转向量。矩阵数字本身不能独立确定所采用的坐标系手性；这里是依据约定解释它。

```text
    [ 0  -1  0 ]
R = [ 1   0  0 ]
    [ 0   0  1 ]

R(x,y,z)^T = (-y,x,z)^T
```

分别把三个单位轴代入：

```text
R(1,0,0)^T = ( 0,1,0)^T   即 +x → +y
R(0,1,0)^T = (-1,0,0)^T   即 +y → -x
R(0,0,1)^T = ( 0,0,1)^T   即 +z 保持不动
```

它保持 z 轴不动，在 xy 平面中把 +x 转到 +y、+y 转到 -x。根据右手定则，右手拇指指向 +z，四指弯曲的正向就是 +x 转向 +y，因此这是绕 +z 轴的正 90° 旋转。观察方向要明确：从 +z 一侧朝原点看，正向旋转为逆时针；从另一侧看则相反。

也可以对照右手系、列向量、主动旋转约定下的标准公式：

$$
R_z(\theta)=\begin{bmatrix}
\cos\theta&-\sin\theta&0\\
\sin\theta&\cos\theta&0\\
0&0&1
\end{bmatrix}
$$

比较可得 `cosθ=0`、`sinθ=1`，所以 `θ=90°+360°k`（k 为整数），通常取 90°。反向旋转 -90° 的矩阵则是 R 的转置，会把 +x 转向 -y。

注意：仅凭 z 不变还不能断定是绕 z 的纯旋转，因为 xy 平面的缩放、错切也能保持 z 不变。本例还满足 `R^T R=I`、`det(R)=1`，并由三个单位轴的完整映射确定旋转。
